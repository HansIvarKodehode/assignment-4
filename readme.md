### Technologies used

For the initial design sketches: Figma was used.
Link to figma project: https://www.figma.com/design/5Erdv82K5Fg9vfcoPmyh9O/Assignment-4-plan--html?node-id=5-120&t=f7B5RxMHK7qNY4WH-1

For the finished gallery project:
-- HTML: The bones, content, and navigation of the site.
-- CSS: All styling.
-- Javascript: used to dynamically render images on screen. Gallery means a lot of images, and rendering them statically with HTML seemed annoying.
-- ChatGPT: The banner video only went from right to left, and with the suggestion that it should also go back for a proper panorama effect I had the AI do it for me, because I don't know the first thing about video editing.

### Pages and functionality

-- Header: Logo, and fully functional navbar. Found on all pages.

-- Footer: Information, and a number of fully functioning links to KHÅK's own pages. Mostly contact info and socials, but also their web store.

-- Main Page(Index): A full video banner. Two iframes to google maps showing both the map location and the building exterior, which is a neat way to let people know exactly where it is. A text section with assorted information about the gallery, the historical collection, the current exhibit, opening times, and assorted links to contact info, socials, and webstore.

-- Current Exhibit(Grafikk): A text section about the exhibit, and a section with dynamically generated images from the exhibit.

-- Kjell Holm exhibit(kihc): A text section about the exhibit, and the man himself, and a section with dynamically generated images from the exhibit. (The file name started as a typo, and just stayed that way.)

-- Gallery: An image gallery dynamically rendering all images, in a random order. So the gallery will not be the same twice, allowing potential users to see something new every time.
